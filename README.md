# 🐾 CAT TOWN: 고양이를 위한 모험

---

## 🎮 게임 소개

**CAT TOWN**은 고양이가 되어 다양한 퍼즐과 모험을 통해 위험을 극복하며 탈출하는 게임입니다.  
플레이어는 고양이가 되어 세 가지 주요 스테이지(지하수로, 공사장, 아파트)를 탐험하고 문제를 해결해야 합니다.

---

## 🐾 Game Story

하루는 주인이 나비를 쫓아 뛰어가는 고양이를 쫓아 차를 타고 떠나버렸습니다.  
어쩔 수 없이 고양이는 스스로 집으로 돌아가야만 하는 상황에 놓입니다.  
여정 도중 다양한 장애물과 퍼즐을 만나며 집으로 가기 위한 고양이의 모험이 시작됩니다.

---

## 🎯 주요 스테이지

### **SCENE 1: 지하수로 (미로)**

- **목표**: 3개의 구성물이 있는 미로를 탐험하며 몬스터를 피해 탈출
- **PLAY**:
  - 미로를 탐험하며 어둠 속에서 길을 찾아야 함
  - 몬스터를 피해 생존

---

### **SCENE 2: 공사장 (점프맵 + 퍼즐)**

- **목표**: 점프맵을 통해 공사장에서 탈출
- **PLAY**:
  - 점프 가능한 장애물을 활용해 길을 탐색
  - 공사장 곳곳의 퍼즐을 풀어 다음 스테이지로 이동

---

### **SCENE 3: 아파트 (방탈출 + 퍼즐)**

- **목표**: 자고 있는 사람을 깨우지 않고 집에서 조용히 탈출
- **PLAY**:
  - 방 안의 단서를 탐색하고, 문제를 해결
  - 퍼즐을 풀어 문을 열고 다음 단계로 이동
